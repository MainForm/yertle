# PMW3901 acquisition and wire contract

Pins: SPI1 PA5 CLK, PA6 MIS, PA7 MOS; GPIO PA4 CS (idle high), PA0 RST
(idle high); PC7 MOT is optional and configured as input, no EXTI handler.
Module 3V3 and common GND. Leave VRE disconnected. Verify the actual module
power circuit before wiring. PA5 shares the Nucleo user LED; PB6 is IMU SCL.
SPI1 is mode 3, MSB first, 1 MHz at APB2 64 MHz. NO DMA: channels 2/3
are already USART3 motor DMA. No IRQ masking during optical transactions.

Initialization is a stepwise state machine: at most one SPI operation per
20ms service call. Power/reset waits and register-table waits span calls.
Expect roughly two seconds until READY. Each SPI transaction is bounded;
errors publish invalid status and retry initialization after one second.
Product ID is rechecked each second. No missing-sensor assumption of zero flow.
First burst after initialization is discarded for displacement/interval use.
Low SQUAL is retained as raw quality data, never certified as reliable flow.
No metres, velocity conversion, axis remapping, or policy observation change.

Initialization/timing reference: Bitcraze official PMW3901 driver,
https://github.com/bitcraze/crazyflie-firmware/blob/master/src/drivers/src/pmw3901.c
The adapted initialization table retains the upstream LGPL-3.0-or-later
copyright/license notice. Chip data: PixArt PMW3901MB product datasheet.
